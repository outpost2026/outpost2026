## 🔥 Featured Project

### [linkedin-mcp-analyzer](https://github.com/outpost2026/linkedin-mcp-custom)

> **MCP server that scrapes your LinkedIn saved jobs, scores them against your profile using a 6-dimension EROI model, and writes structured reports + market intelligence.**
>
> Of 49 analyzed jobs, only 12% were worth pursuing — this tool tells you which ones.
>
> `Python` `MCP` `Playwright` `LinkedIn API` `EROI scoring`
